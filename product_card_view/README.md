# Product Card View

模块技术目录：`product_card_view`（版本 `19.0.1.0.1`，**待目标环境验证**）。

面向外贸 SOHO 的现代产品列表卡片视图：在**库存应用 → Products 容器下新增独立的「Product Cards」菜单**，
官方默认的产品列表 / 看板 / 表单视图均保持原样。

## 功能

- **图片轮播**：每张卡片顶部展示产品主图；存在多张图时支持左右箭头、滑动翻页与右下角计数。
  多图来源遵循 `product_image` 的数据结构：
  - 未选择变体：模板主图 + 模板共享图库（`product.image.gallery`）；
  - 选择变体：变体主图（无变体图时由 Odoo 原生回退模板主图）+ 变体专属图库；
  - 模板层与变体层两套图**互不叠加**。
- **信息区**：卡片下方显示 `title`（产品名）、`reference`（`default_code`）与 `on hand`（在手数量）；
  默认口径为模板层（参考号 + 全部变体在手总量），点选变体后切为该变体的参考号与该变体在手。
- **变体按钮行**：多变体产品在卡片底部按属性分行（一属性一行）渲染按钮；点击即切换到对应变体，
  图片 / 参考号 / 在手同步刷新。再次点击同一值可取消，回到模板层。
  不可与当前已选属性组合出变体的按钮会自动禁用，避免点出“不存在的组合”。
- **瀑布流布局**：不同高度的卡片在 CSS 多列中自然堆叠，按屏幕宽度自适应列数（响应式）。

## 设计说明

- **不新增模型 / 字段**：纯 `product.template` 方法扩展 + JSON 控制器路由，
  无 `security/ir.model.access.csv` 需求（沿用产品与库存既有权限）。
- **后端一次性装配**：页面每批产品只请求一次 `/product_card/payload`，
  一次返回模板信息、全部变体（含属性组合 / 参考号 / 在手）、两套图库引用，避免每个卡片单独请求。
- **前端**：注册 `views` 注册表项 `product_cards`，视图 arch 声明 `js_class="product_cards"` 启用；
  渲染器 primary 继承 `web.KanbanRenderer`（分组 / 空态 / 翻页等沿用），仅替换记录卡片组件。
- **库存口径**：在手数量读取 `product.product.qty_available`（含未库存追踪产品显示 `—`）。
- **依赖**：`product_image`（图库模型与数据源）、`stock`（在手与库存应用菜单）；依赖最小化，不引 `sale`。

## 安装

将仓库目录加入 `addons_path` 后：

```bash
odoo -d <db> -i product_card_view --stop-after-init    # 首次安装
odoo -d <db> -u product_card_view --stop-after-init    # 升级（前端资源改动后必须 -u 并强刷浏览器）
```

安装后进入 **库存应用 → Products → Product Cards** 即可看到卡片视图；
顶部视图切换按钮可切到 List / Form。

## 使用提示

- 单变体产品（无组合可选）卡片不显示变体按钮行；
- 模板层卡片标题 / 参考号取自模板，点选变体后参考号与在手取该变体值（变体未单独填参考号时回退模板参考号）；
- 产品表单中的“产品 / 变体图片图库”在卡片上按第 1 节规则展示。

## 待验证清单（目标环境）

> 本仓库不含 Odoo 运行时，需在已部署环境验证以下项目，通过后再更新状态为「已验证」。

1. `odoo -d <db> -i product_card_view --stop-after-init` 安装无报错，启动日志无新 WARNING。
2. 后台出现「库存应用 → Products → Product Cards」，打开默认即为卡片视图，无图产品不裂图。
3. 上传多图（模板共享图库）的产品：卡片顶部可左右箭头 / 滑动切换图片，计数正确，其余产品不受影响。
4. 多变体产品（如 2 颜色 × 3 尺寸 = 6 变体）：
   - 卡片底部出现两行按钮（颜色 2 个、尺寸 3 个），点击后图片 / 参考号 / 在手同步切换；
   - 再点同一值取消回到模板层（模板主图 + 模板图库、总在手）；
   - 颜色为 Blue 时，只存在 Blue 尺寸才可选（禁用的按钮灰色不可点）。
5. 变体各自维护专属图库（`product_image` 变体入口上传）时，选中变体后只显示该变体图集（不回显模板图库）。
6. 非库存追踪产品（服务等）卡片在手显示 `—`；库存产品正常显示（模板层为各变体和）。
7. 窗口缩窄 / 放大时卡片瀑布流列数自适应；分组搜索（Group By）与搜索过滤可用；
   官方默认产品列表 / 看板视图样式未受影响。
8. 中英文双语：英文界面默认显示英文；切换简体中文后菜单、动作、help、图片按钮与「在手 / 参考号」提示为中文。
9. 权限：普通库存内部用户可正常浏览卡片数据（含在手）。

## 回滚方式

卸载模块即可移除新增菜单与视图，官方视图从未被修改：

```bash
odoo -d <db> -u product_card_view --stop-after-init && # 如需彻底回滚再执行：
odoo -d <db> --stop-after-init --uninstall product_card_view
```
