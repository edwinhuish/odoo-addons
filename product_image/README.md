# 产品图片

Odoo 19 产品模块扩展，用于在外贸 SOHO 场景下为一个产品维护多张图片，在原有图片位置直接支持多图浏览，不新增页签，保持界面简洁。

> 模块技术名：`product_image`（原名 `product_multi_image`，于 19.0.2.0.0 改名）。模型名仍为 `product.image.gallery`（避开 `website_sale` 的 `product.image`，仅依赖 `product`）。

---

## 功能概述

- 在产品表单原有图片位置（头像区域）直接支持多图浏览，不新增页签、不增加导航层级
- **主图与图库解耦**：原生主图 `image_1920` 由原生字段独立管理（列表 / 看板 / 报价单展示它），后端图库不反向同步主图
- **展示序列**：原生主图（若有）作为浏览序列第一张，其余图库图片按 `sequence` 跟在后面；主图永远在最前（无角标，靠首位隐含）
- **列表第一位即主图**：主图为空时上传的图直接成为主图（首位）；主图已有值时上传追加为图库记录
- **删除入口只在缩略图网格，且先确认**：弹窗大图预览区（任何图片）不显示删除按钮；缩略图网格中每张图（含主图）右上角 ×——点击先弹确认框（含该图缩略图；主图提示自动提升）再删：图库图删除记录，删除主图自动提升图库首张为主图（图库空则清空主图）
- **缩略图拖动排序**（19.0.2.3.0）：管理弹窗网格内直接拖动图库缩略图调整顺序（拖动时其余缩略图平滑避让，可拖到任意图库位置），松手后顺序写回图库 `sequence`（随产品保存）；主图固定首位不参与拖动；排序后再上传的图片仍追加到末尾
- **删除确认与批量删除**（19.0.2.3.0）：任何删除（单张右上角 ×、批量）都先弹确认框，并显示待删图片缩略图清单（主图带「主图」标签 + 自动提升提示）；header「批量删除」进入勾选模式，可多选（含主图）后一次删除（先删图库、后删主图）
- **主图名称留空**（19.0.2.3.0）：大图预览选中主图时下方名称行留空，不显示“主图”字样（固定行高占位，弹窗尺寸稳定）
- **弹窗布局：大图固定、缩略图铺满余量**：上半区大图列固定 250px（大图盒 250×250），名称单行截断 + 提示文字固定行高——切换任意图片（含有无图片）时弹窗尺寸不变；右侧缩略图网格占满除大图与间距外的全部宽高，图片较多时超高内部滚动（图片增减同样不改变弹窗高度）
- **主图放大 2 倍**（180×180），移除上一张 / 下一张按钮与序号
- **悬浮局部放大**：鼠标悬浮主图区时在左侧（空间不足转下侧 / 右侧）显示放大镜面板，只放大鼠标所在区域的局部，移动鼠标放大区域实时跟随
- **点击预览**：点击主图区弹出全屏预览弹窗，支持放大、缩小、重置、旋转（按钮 + 鼠标滚轮 + 键盘）
- **右侧竖排缩略图**：仅用于点击切换当前展示图（**编辑态缩略图不放删除按钮**，删除图库图在「图片管理」弹窗内进行）；选中项带一圈蓝色边框
- **缩略图溢出滚动**：缩略图总高超出主图高度时，顶部 / 底部出现上下滚动按钮
- **图片管理弹窗**（编辑态）：点击缩略图末端「+」占位符弹出；**上半部分**大图预览（**仅作预览、无删除按钮**）+ 平铺缩略图网格（**每张缩略图含主图右上角 × 可删**：图库图删记录，删除主图自动提升图库首张为新主图；点击缩略图只切换弹窗内大图，不影响页面主图），**下半部分**上传 dropzone（点击选文件 / 拖放图片 / Ctrl+V 粘贴三种方式；上传中每张图即时显示缩略图 + 转圈动画；Ctrl+V 粘贴上传后**不自动关闭**；**任一方式上传都不改变页面当前显示的大图**）；主图为空时上传图成为主图，否则追加图库；右上角为正方形「关闭 ×」按钮（无文字，hover 变红）
- 上传无需 `web_image_paste` 依赖，内建粘贴 / 拖放
- 每张图片继承 `image.mixin`，自动生成多尺寸（1920/1024/512/256/128）
- 产品列表展示图片数量；看板/报价单展示主图缩略（原生 `image_128` 即主图缩略）
- 删除产品时图片行级联清理，无孤儿数据
- 仅依赖 `product`，不依赖 `website_sale`，避免与 eCommerce 冲突

## 核心设计

| 设计点 | 说明 |
|--------|------|
| 原位多图浏览 | 自定义 `product_image_gallery` widget 替换原生 `image_1920` 字段 widget，同一位置渲染主图 + 右侧缩略图列 |
| 独立明细模型 | 补充图存于 `product.image.gallery`，继承 `image.mixin` 复用多尺寸 |
| 模型名避开 `product.image` | 刻意用 `product.image.gallery`，避免与 `website_sale` 的 `product.image` 冲突 |
| 主图独立 | 产品主图 `image_1920` 由原生字段独立管理，图库不反向同步 / 不覆盖 / 不清空；列表 / 看板展示主图 |
| 展示序列 | widget 把原生主图拼到序列第一位，图库图片按 `sequence` 跟在后面；主图永远在最前 |
| 浏览不写库 | 切换为纯前端 `currentIndex` 状态，不写库；删除主图（提升/清空）与图库增删走 One2many record 操作 |
| 悬浮放大 / 点击预览 | 均为纯前端只读行为，不写库；只读态也可用 |
| 级联清理 | 删除产品时图片行 `ondelete='cascade'`，无孤儿数据 |

## 模型字段

### `product.template`（扩展）

| 字段 | 类型 | 说明 |
|------|------|------|
| `image_gallery_ids` | `One2many` → `product.image.gallery` | 该产品的补充图片（不含主图） |
| `image_gallery_count` | `Integer`（compute） | 图库图片数量（不含主图） |

### `product.image.gallery`（新建）

| 字段 | 类型 | 说明 |
|------|------|------|
| `image_1920` | `Image`（继承自 `image.mixin`） | 图片源数据，自动生成 1024/512/256/128 多尺寸 |
| `image_128` | `Image`（related） | 128 缩略，用于 widget 缩略图展示 |
| `name` | `Char` | 图片名称，同一产品内不可重复 |
| `sequence` | `Integer` | 排序，数值小的在前；图库图片在缩略图列表中的展示顺序（主图始终在最前） |
| `active` | `Boolean` | 启用状态，可停用而不删除 |
| `note` | `Char` | 备注 |
| `product_tmpl_id` | `Many2one` → `product.template`（required, index, cascade） | 所属产品 |

## 视图

- **产品表单**：头像区域 `image_1920` 字段 widget 改为 `product_image_gallery`，同一位置支持多图浏览/悬浮放大/点击预览/「+」打开图片管理弹窗（删除与上传）/粘贴新增
- **产品列表**：新增「图片数」列（可选显示）
- **产品看板**：原生已展示 `image_128`（即主图缩略），无需改动
- **图库独立视图**：`产品图片` 动作，供按需检索与维护

## 交互说明

### 展示序列
- 浏览序列第一项 = 原生主图（`image_1920` 字段值，若有），其后 = 图库图片按 `sequence` 升序。
- 主图永远在序列最前（只要有主图）；图库图片跟在后面。
- 主图区（左侧大图）显示当前选中项；默认选中第一项（主图）。

### 主图区与悬浮局部放大
- 主图区按 180×180 显示（原生 90×90 的 2 倍），无上一张 / 下一张按钮、无序号。
- 鼠标悬浮主图区：在左侧（空间不足转下侧/右侧）弹出 320×320 放大镜面板，**只放大鼠标所在区域的局部**（用当前项 `image_1920` 做 background，`background-size` 放大，`background-position` 跟随鼠标相对图片内容的百分比）。移动鼠标，放大区域实时跟随。同时主图上鼠标处显示蓝色半透明方块，标示当前实际被放大的区域。
  位置优先级：左侧 → 下方 → 右侧（按可用空间自动选择）。
- 点击主图区：弹出全屏预览弹窗（预览当前选中项）。

### 预览弹窗（放大 / 缩小 / 旋转）
- **放大 / 缩小**：底部按钮，或鼠标滚轮，或键盘 `+` / `-`。
- **重置缩放**：按钮或键盘 `0`。
- **旋转**：按钮或键盘 `r`。
- **关闭**：`Esc` / `q` / 点击背景空白处 / 右上角 ×。

### 右侧缩略图列
- 缩略图 56×56，竖向排列于主图右侧；第一项为主图（无角标，靠首位隐含），其后为图库图片。
- 点击缩略图切换当前展示项（纯前端，不写库）。
- **主图删除经弹窗缩略图 ×（先确认）**：头像区缩略图列无删除 / 替换按钮；「图片管理」弹窗大图区仅作预览、无删除按钮，删除在缩略图网格——主图项亦有 ×，点击先弹确认框，确认后删除（图库首张自动提升为新主图，图库空则清空主图字段）。主图为空时上传第一张图即成为主图，主图已有值时上传追加为图库。
- 缩略图总高超出主图高度（180px）时，顶部 / 底部出现上下箭头按钮，点击滚动一屏。
- 选中缩略图带一圈蓝色边框（2px，真实 border，四周完整显示）。

### 图片管理弹窗（「+」，上半管理 + 下半上传）
- 点击缩略图末端「`+`」占位符，弹出图片管理弹窗（编辑态）。
- **上半部分**：
  - 左侧**大图预览**：跟随弹窗内选中项；**仅作预览，对任何图片都不显示删除按钮**。**大图名称行**：选中主图时留空（不显示“主图”），图库图显示其名称。
  - 右侧**平铺缩略图网格**：显示全部图片（主图 + 图库）；**每张缩略图（含主图）右上角 × 可删除（先确认）**；点击缩略图只切换弹窗内大图，**不影响页面头像区展示的主图**。
  - **拖动排序**：直接拖动图库缩略图可调整顺序——拖动时其余缩略图平滑避让、可拖到任意图库位置（拖到网格上 / 下边缘自动滚动），松手落位后写回图库 `sequence`（保存产品时一并生效）；**主图固定首位、不参与拖动**；排序后再上传的新图追加到末尾。
  - **删除图片（确认后执行）**：单张点右上角 × 弹确认框（含该图缩略图）；主图另有“图库首张自动提升 / 图库空则清空”提示。删除图库图 = 直接删该图库记录（不影响主图）；删除主图 = 图库首张自动提升为新主图（移动、不重复展示），图库为空则清空主图字段。
  - **批量删除**：modal-header 右侧「批量删除」进入勾选模式——每张缩略图左上角出现勾选圈，点击勾选（主图亦可）；header 实时显示已选数量并提供「删除 / 取消」。点「删除」先弹**批量删除确认框**：列出全部所选图片缩略图（主图带「主图」标签）+ 总数 + 主图处理提示；确认后按“先图库、后主图”顺序删除。
- **下半部分（dropzone + 上传队列）**：
  - **点击选文件**：点击拖放区域 → 唤起系统文件选择。
  - **拖放上传**：把图片文件拖到拖放区域（区域高亮），松开即上传。
  - **Ctrl+V 粘贴**：弹窗打开时焦点在弹窗上，按 `Ctrl+V` / `Cmd+V` 粘贴剪贴板图片即上传；**上传后弹窗不自动关闭**，可继续粘贴 / 管理。
  - **上传动画**：每张上传中的图片立即以本地预览显示缩略图 + 转圈动画，完成后自动移除并出现在上方网格（可连续多张）。
  - 上传规则：主图为空时上传图成为主图（首位），主图已有值时追加为图库记录。
  - **上传不改页面大图**：点击 / 拖放 / Ctrl+V 任一方式上传，都只写记录，页面头像区仍显示上传前那张图。
- 删除 / 上传后网格实时刷新，弹窗不关闭不重建，可连续操作。
- 关闭：header **最右侧正方形「×」按钮**（无文字、占满 header 高度、hover 背景变红），或 `Esc` / 点击背景空白。

## 安装与使用

### 全新安装

1. 将 `product_image` 目录放入 Odoo 19 的 `addons_path`
2. 更新应用列表后安装模块：`产品图片`
3. 打开任意产品表单，头像区域即多图控件

### 从旧模块 `product_multi_image` 切换

旧模块 `product_multi_image`（19.0.1.0.0）在目标环境**尚未验证安装**，无生产数据需迁移。
切换方式：

1. 在目标环境**卸载** `product_multi_image`（设置 → 应用 → 卸载，或命令行卸载）。卸载会级联删除 `product.image.gallery` 表数据（仅测试数据）。
2. 将 `product_image` 目录放入 `addons_path`，更新应用列表。
3. 安装模块：`产品图片`。

> 不需要写迁移脚本：模块技术名变更在 Odoo 中视为「不同模块」，新模块全新安装即可；
> 旧模块未在目标环境安装过，无字段 / 数据需迁移。

### 操作
- 点击缩略图末端「`+`」占位符弹出「图片管理」弹窗：上半部分大图预览（**无删除按钮，仅预览；选中主图时名称行留空**）+ 平铺缩略图网格（**每张缩略图含主图右上角 ×，点击先确认后删除**；删图库图删记录，删主图自动提升图库首张；**直接拖动图库缩略图可排序**，主图固定首位），下半部分 dropzone 上传（点击选文件 / 拖放 / Ctrl+V 粘贴，上传中即时显示缩略图与动画，粘贴后不自动关闭）
- header 右侧「批量删除」：进入勾选模式逐张勾选（含主图），header 显示已选数量，确认框列出全部所选缩略图后一次删除（先删图库、后删主图）
- 弹窗内点击缩略图只切换弹窗大图，不影响页面头像区展示；任一方式上传都不改变页面大图；右上角正方形「关闭 ×」按钮 / `Esc` / 点背景关闭
- 主图为空时上传第一张图直接成为主图；已有主图时上传追加为图库（主图 / 图库图均可在弹窗缩略图右上角 × 删除——先确认，删除主图自动提升图库首张）
- 多图时点击右侧缩略图切换当前展示项（选中项蓝色边框），悬浮主图区查看放大，点击主图区进入全屏预览
- 保存产品后：主图由原生字段管理，列表/看板展示主图；图库只管补充图

### 执行流程

1. 首次安装：`odoo -d <db> -i product_image --stop-after-init`
   自动建表、加载权限、注册 `product_image_gallery` widget 前端资源
2. 产品表单头像区域验证主图作为首张、2 倍显示、悬浮放大、点击预览（放大/缩小/旋转）
3. 多图时验证右侧缩略图切换、滚动；点「+」打开图片管理弹窗（大图区无删除按钮、点击缩略图只切弹窗大图、点击/拖放/Ctrl+V 上传且即时显示缩略图 + 动画）
4. 管理弹窗增强验证：选中主图大图名称行留空（切回图库图显示名称）；拖动图库缩略图排序（主图不可拖、其余平滑避让、可拖到末尾）并保存产品后重开确认顺序保持、之后上传的新图追加末尾；点缩略图右上角 × 先弹确认（含缩略图与主图提示）；header「批量删除」勾选多张 → 批量确认框含全部缩略图清单 → 确认后删除且页面 / 网格同步
5. 在图片管理弹窗内粘贴图片验证新增图库记录且**弹窗不自动关闭**，可连续粘贴多张；关闭弹窗后页面大图仍为上传前那张（**上传不改变页面大图**）
6. 验证主图独立：上传/删除图库图片，产品主图（列表/看板）不变
7. 删除产品验证级联清理

### 异常情况与处理

- 主图与图库均无值：头像区域显示占位图与「暂无图片」提示
- 历史产品有主图无图库：主图作为序列首张展示，无图库缩略图；上传图库图后跟在主图后面（不影响主图）
- 同一产品重复图片名称：`@api.constrains` 阻止并中文提示
- 粘贴无反应：粘贴入口在「图片管理」弹窗内（打开后自动获焦，按 `Ctrl+V` 粘贴），头像区域本身不再直接响应粘贴
- widget 不生效：前端资源缓存，`-u product_image` 升级后强刷浏览器
- 切换不写库：浏览切换是纯前端状态，不触发保存；图库图删除、主图删除（自动提升图库首张）、上传、拖动排序才写库（均需产品表单保存后落库）
- 缩略图无法拖动排序：需 ≥2 张图库图（主图固定不参与拖动）；处于批量删除勾选模式时不支持拖动（先退出勾选）
- 拖动排序后顺序未保存：拖动只更新图库记录 `sequence` 为待保存变更，需在产品表单点「保存」后写库
