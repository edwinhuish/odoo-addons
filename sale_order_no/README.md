# 订单编号

Odoo 19 销售模块扩展，用于在外贸 SOHO 场景下为报价单/销售订单生成按客户维度年度递增的订单编号。

---

## 功能概述

- 单据编号格式：**客户编码 + 两位年份 + 客户本年度流水号**
- 示例：`DZ2602` 表示客户 `DZ` 在 `2026` 年的第 `2` 张单据
- 报价单与销售订单统一使用同一套编号规则

---

## 核心设计

| 设计点 | 说明 |
|--------|------|
| 不改动原生 reference | 系统内部仍保留 `SOxxxx` 作为主键，`order_no` 用于对外展示、打印、详情页标题、列表 API |
| 创建时快照 | 客户编号、年度流水号与订单编号在创建时一次性写入，后续修改客户信息或订单日期不影响历史单据 |
| 流水号一次性分配 | 创建时即分配年度流水号，作废/取消的单据仍占用原流水号，不会重算 |
| 自动避让重号 | 生成编号时若发现已被占用（历史导入、手动改号），自动递增流水号直到拿到可用编号 |
| 双重唯一校验 | 保存时 `@api.constrains` 给出中文提示，数据库层另有 `UNIQUE(order_no)` 约束兜底 |
| 客户编码校验 | 联系人 `ref` 字段仅允许大写纯英文字母，保存时自动转大写 |
| 显示名称统一 | `display_name` 优先返回 `order_no`，为空时回退到原生 `name` |
| 编号可搜索 | Many2one 下拉、搜索建议、快速搜索与列表搜索框均可按订单编号命中 |
| 列表 API 替换 | `web_search_read` 返回的列表记录中，`name` 字段值被替换为 `order_no` |
| 批量补号 | 列表视图"动作 → 生成订单编号"，为尚未编号的单据补号 |
| 打印预览显示 | 报价单/订单/形式发票打印报表正文优先显示 `order_no`，未分配时回退到系统编号 |
| PDF 文件名 | 打印生成的 PDF 文件名包含 `order_no`（如 `Quotation - DZ2602.pdf`），替代原生 `SOxxxx` 命名 |
| 门户预览 | 后台预览客户门户（带"返回编辑模式"提示）时，门户页面的面包屑与 H2 标题也使用 `order_no` |

---

## 模型字段

### `res.partner`

- `ref`（继承）：作为客户编码使用，格式校验为大写英文字母，界面标签显示为"客户编号"

### `sale.order`

| 字段 | 类型 | 说明 |
|------|------|------|
| `buyer_ref` | `Char` | 客户编号快照，创建时从 `partner_id.ref` 复制；未设置时为 `UNK` |
| `buyer_order_idx` | `Integer` | 客户年度流水号，创建时分配 |
| `order_no` | `Char` | 订单编号，创建时自动生成，可手动编辑，唯一性由应用与数据库双重保证 |

### 可用方法

| 方法 | 说明 |
|------|------|
| `action_generate_order_no()` | 为选中单据中尚未编号的记录补号，完成后弹出结果提示 |

## 视图与报表

- **联系人表单视图**：把原生 `ref` 字段标签改为"客户编号"，并补充占位提示
- **销售订单表单视图**：标题区显示可编辑的 `订单编号`，原生 `name` 保留但隐藏
- **销售订单列表视图**：编号列显示 `订单编号`（报价单与销售订单列表同时生效）
- **销售订单列表 API**：`web_search_read` 返回的每条记录中，`name` 字段值被替换为 `order_no`
- **销售订单搜索视图**：顶部搜索框直接匹配订单编号，另有独立的"订单编号"筛选项
- **打印报表**：报价单、销售订单、形式发票统一用 `订单编号` 替代系统原生编号
- **PDF 文件名**：覆盖三个 `ir.actions.report` 的 `print_report_name`，未分配编号时回退到系统编号
- **客户门户预览**：门户页面的面包屑与 H2 标题也使用 `order_no`

### PDF 文件名覆盖范围

| 报表动作 xmlid | 菜单项 | 文件名格式 |
|--------|--------|--------|
| `sale.action_report_saleorder` | 打印 → PDF 询价 | `Quotation - <order_no or name>.pdf` / `Order - <order_no or name>.pdf` |
| `sale.action_report_pro_forma_invoice` | 打印 → 形式发票 | `Proforma - <order_no or name>.pdf` |
| `sale_pdf_quote_builder.action_report_saleorder_raw` | 打印 → 报价单/订单 | `Quotation - <order_no or name>.pdf` / `Order - <order_no or name>.pdf` |

> 实现细节与踩坑记录见 `AGENTS.md` L2 踩坑档案 P1。

## 安装与使用

1. 将 `sale_order_no` 目录放入 Odoo 19 的 `addons_path`
2. 更新应用列表
3. 安装模块：`订单编号`
4. 在联系人表单中为客户设置"客户编号"（大写英文字母）
5. 创建报价单或销售订单，系统会自动生成订单编号

### 手动改号

在表单标题区直接编辑订单编号即可。保存时会校验唯一性，重复时给出提示并拒绝保存。

### 批量导入历史单据

导入时直接写入 `order_no` 即可保留原编号，系统不会覆盖：

- 若导入的编号形如 `客户编码 + 两位年份 + 流水号`，会自动还原流水号，后续新建单据可接续编号
- 导入后若有单据未带编号，可在列表勾选后执行"动作 → 生成订单编号"补号

## 升级注意

- 本模块不再保留 `migrations/` 目录（已删除历史迁移脚本），仅支持全新安装；已有数据库若安装过旧版本，需先卸载再重新安装
- `19.0.1.7.0` 起 PDF 文件名覆盖依赖 `sale_pdf_quote_builder` 模块，安装前需确认该模块已在 addons_path 中可用
- 升级后强刷浏览器（Odoo 资源有缓存）
